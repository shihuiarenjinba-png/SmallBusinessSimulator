# SmallBusinessSimulator — 小さな会社の経営ゲーム

**GitHub feature開発版・Microsoft Store販売HOLD。** 本作の原本はこのfeatureブランチ。mainは初期化用READMEのみで保護する。

「何を・いくらで・どれだけ売るか」を軸に、価格、仕入れ、在庫、広告、従業員、設備、借入と返済を考えるオフライン経営ゲームです。専門的な経済モデルは内部で計算し、画面には商品と売上などの経営判断だけを表示します。

## 操作
1. 商品の販売価格と仕入数量を選ぶ（価格別の需要予想を表示）
2. 従業員・広告を設定する（設備・品質・借入・返済は折りたたみ）
3. 1か月営業して、売上・利益・在庫・販売機会の損失を見る

初期はコーヒーのみ。4か月目からサンドイッチを導入できます。表示は単一画面と折りたたみ設定。通信・アカウント・現金取引・広告はありません。

## 確認
Node.js 20以降で `npm test`（依存パッケージのインストール不要）。ブラウザでは `index.html` をローカルで開きます。JavaScriptの静的チェックやUIのテストも販売前に実施します。サポート対象の最終Windows版は、正式Identity確定後にコード担当が独立フォルダでElectron/MSIXパッケージ化します。

店舗拡張、在庫の劣化、従業員育成、競合の戦略的反応、十分な物語/達成演出、年単位バランス、長時間試遊、初見の操作検査、Windows 11 DPI/保存復元、正式MSIX/WACK、権利・価格・Store商品ページ。GitHubのソースチェックのみで販売可にはしません。

金融モデルは架空のゲーム数式であり、現実の会計・価格予測・投資助言ではありません。
